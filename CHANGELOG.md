# Changelog

Formato: [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/). Versionado semántico.

## [1.0.0] - 2026-10-03
### Añadido
- Primera versión pública (documentación, licencia GPL-2.0-or-later y hoja de ruta de publicación).
- Código fusionado en un solo plugin (`wp-accesibilidad/`); colores y enlace de guía pasan a ajustes; claves de localStorage `pa_a11y_*`.
- Funciones: panel ♿, modo oscuro global, fuente para dislexia, guía de lectura, insignia de formato accesible y schema de accesibilidad.

Este historial empieza en 1.0.0; el desarrollo anterior fue interno de librosmedellin.com.
